# COIN TOWER 1.0

Die vollständige, eigenständig laufende Browser-Vollversion von Coin Tower.

## Start
Einfach `index.html` in Chrome, Edge, Firefox oder Safari öffnen. Es ist keine Installation und kein Server nötig.

## Struktur
- `index.html` – Oberfläche
- `style.css` – komplette mobile-first UI im finalen Coin-Tower-Look
- `game.js` – Spielzustand, Upgrades, Prestige, Mega Prestige, Arena
- `effects.js` – Münz-, Toast- und Animationseffekte
- `save.js` – LocalStorage, Offline-Einnahmen, Export/Import
- `shop.js` – 50 Upgrade-Jobs und Shoplogik
- `script.js` – UI, Events und Spielschleife
- `assets/coin.svg` – finale Coin-Tower-Münze

## Kernsysteme
- 50 Upgrade-Jobs
- 5 Kaufmodi: ×1, ×10, ×25, ×100, MAX
- Klick-Einnahmen + CPS
- kritische Treffer
- 15+ Zahleneinheiten
- Prestige und Mega Prestige
- Kristall-Schmiede ab Prestige 20
- Battle Arena mit 9 Gegnern
- Battle Token Shop
- Achievements
- Statistikseite
- Autosave
- Offline-Einkommen bis 8 Stunden
- Save Export/Import
- kompletter Reset
- mobile Navigation oben/unten

## Hinweis
Der Spielstand wird lokal im Browser gespeichert. Beim Testen auf dem Handy bleibt er an den Browser gebunden.
